## 🚀 Tecnologias

Este projeto foi desenvolvido com as seguintes tecnologias e ferramentas:

- **HTML5** (estruturação semântica)
- **CSS3** (estilização, variáveis CSS, Flexbox e responsividade)
- **JavaScript** (manipulação do DOM e alternância de temas)
- **Git e GitHub** (controle de versão e hospedagem)
- **Figma** (prototipação e referência visual)

## 💻 Projeto

O **DevLinks** é um agregador de links para servir como cartão de visitas digital, reunindo perfis profissionais, portfólio e redes sociais em uma única interface responsiva.

### Principais funcionalidades:
- **Alternância de Tema (Light/Dark Mode):** Troca dinâmica entre os modos claro e escuro com alteração automática da foto de perfil e das cores da interface.
- **Design Responsivo:** Adaptação fluida para dispositivos móveis e telas maiores.
- **Links Interativos:** Botões estilizados com efeitos de transição e ícones integrados via Ionicons.
